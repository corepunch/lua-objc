# Production parity implementation — 2026-09-09

Neither delivery gate is complete. This records implementation and verification
following [the source audit](audit-2026-09-09.md); it does not replace the broader
coverage contract or certify Adventure Arena as 1:1.

## Implemented

- Removed the batch-only stack sizing, text-width subtraction, and padding
  wrappers. Both candidates now exercise the ordinary Lua/native constructors.
- AppKit and UIKit stacks measure current content, inherit flexibility by axis,
  preserve explicit zero sizes, ignore hidden siblings, and distribute weighted
  spacers. Constrained HStacks negotiate text widths; native labels wrap and
  recover their intrinsic size after resizing or editing.
- Corrected AppKit multiline paragraph metrics, native label drawing mode, and
  asymmetric top/bottom padding. Text rendering remains a native NSTextField.
- Corrected scroll document measurement and clipping. AppKit preserves the top
  reading position across viewport changes; UIKit no longer resets scroll offset
  on every layout pass or inherits old document widths/heights.
- Native macOS tabs preserve initial/current selection and fill their parent.
  Selected content receives layout after native tab selection and resizing.
- Added AppKit NavigationStack through public NSPageController. UIKit uses
  UINavigationController and restores native titles/Back behavior for pushed
  screens. Both expose depth/currentController and retain root page state.
- UIKit TextField now separates value from placeholder and dispatches native
  editing/Return events through the same onChange/onCommand contract as AppKit.
- AppKit Image accepts the path property and uses native NSImageView centering
  and clipping for aspect fill. Image modes and clear/restore round-trip on both
  platforms. Plain/icon AppKit buttons use NSButton instead of an opaque compound
  card. Stack overlays can opt out of hit testing with allowsHitTesting=false;
  the hero artwork button is reachable beneath its caption overlay.
- Adventure Arena catalog data now preserves all nine sorted source entries,
  descriptions, genres, corrected counts, and all 21 reviews. Views and session
  state were extracted from the controller. Catalog → detail → session stays in
  one app root, with a typed-command composer and startup-error recovery.
  The fabricated ongoing-session row was removed.
- ZIL loading and execution restore global IO/import paths after success or
  failure, including streamed iOS reads. This is not full runtime-state isolation
  or deterministic replay.
- Screenshot capture applies requested size before its settling interval, uses
  process arguments instead of shell interpolation, and returns failure for
  missing captures. Native macOS captures required execution outside the sandbox;
  sandboxed captures could not access WindowServer images.
